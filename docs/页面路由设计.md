# ClassNest 页面路由设计

> 依据：`docs/tech.md` 第 51 节 Router 与第 26-50 节页面定义。

---

## 1. 路由总览

项目不设登录页、首页 Dashboard 或欢迎页；应用打开直接进入主课表。

| 路径 | 页面/View | 说明 |
| --- | --- | --- |
| `/` | ScheduleView | 主课表，应用默认落地页 |
| `/schedules` | ScheduleManagerView | 多课表管理：查看/切换/复制/重命名/删除 |
| `/schedule/:id/settings` | ScheduleSettingsView | 课表设置（基本设置 / 时间表 / 外观 / 高级） |
| `/course/new` | CourseEditorView | 新增课程（与编辑复用同一组件） |
| `/course/:id/edit` | CourseEditorView | 编辑课程 |
| `/import` | ImportView | 导入（CSV 首期，HTML/备份后续） |
| `/export` | ExportView | 导出（CSV / ICS / JSON 备份） |
| `/settings` | GlobalSettingsView | 全局设置（主题、语言、启动行为等） |

## 2. 不进入路由的能力

- 课程详情：使用 `NDrawer`（CourseDetail），不使用路由；
- 新建课表：使用 `NDrawer` / `NModal`（ScheduleCreateDialog），不单独建页；
- 导入来源选择、导入预览：由 ImportView 内的组件流程完成。

## 3. 路由结构（Vue Router 4）

```ts
const routes = [
  {
    path: '/',
    name: 'schedule',
    component: () => import('@/views/ScheduleView.vue'),
    meta: { title: '我的课表' }
  },
  {
    path: '/schedules',
    name: 'schedule-manager',
    component: () => import('@/views/ScheduleManagerView.vue'),
    meta: { title: '课表管理' }
  },
  {
    path: '/schedule/:id/settings',
    name: 'schedule-settings',
    component: () => import('@/views/ScheduleSettingsView.vue'),
    props: true,
    meta: { title: '课表设置' }
  },
  {
    path: '/course/new',
    name: 'course-new',
    component: () => import('@/views/CourseEditorView.vue'),
    meta: { title: '新增课程' }
  },
  {
    path: '/course/:id/edit',
    name: 'course-edit',
    component: () => import('@/views/CourseEditorView.vue'),
    props: true,
    meta: { title: '编辑课程' }
  },
  {
    path: '/import',
    name: 'import',
    component: () => import('@/views/ImportView.vue'),
    meta: { title: '导入' }
  },
  {
    path: '/export',
    name: 'export',
    component: () => import('@/views/ExportView.vue'),
    meta: { title: '导出' }
  },
  {
    path: '/settings',
    name: 'settings',
    component: () => import('@/views/GlobalSettingsView.vue'),
    meta: { title: '全局设置' }
  },
  {
    path: '/:pathMatch(.*)*',
    name: 'not-found',
    redirect: '/'
  }
];
```

## 4. 路由模式

桌面打包场景（Tauri WebView 加载本地资源）推荐使用 **Hash 模式**（`createWebHashHistory`），避免打包后刷新路径 404；开发期也可使用 `createWebHistory`。两种模式由环境配置切换，业务路由定义保持一致。

## 5. 页面间导航

```text
主课表 /
 ├─ 新增课程         → /course/new
 ├─ 点击课程卡        → NDrawer 课程详情（不跳路由）
 │    └─ 编辑        → /course/:id/edit
 ├─ 课表名/切换器     → NDropdown 切换 或 打开 /schedules
 ├─ 课表设置         → /schedule/:id/settings
 ├─ 导入             → /import
 └─ 导出             → /export

全局设置               → /settings
```

交互规则：

- 课程详情、新建课表、确认删除等高频轻量交互优先 Drawer / Dialog，而非新增路由；
- 删除课表必须 `NDialog` 确认，并明确提示会级联删除课程、时间段、调课与外观配置；
- 设置页使用 `NTabs`，四个 Tab 之间不改变 URL；
- 导入/导出是流程页，内部通过组件状态推进步骤（选择类型 → 预览 → 确认）。

## 6. 路由守卫

无登录、无权限体系，因此不设鉴权守卫，只做：

1. **首次启动处理**：`scheduleStore.loadSchedules()` 完成后若 `schedules` 为空，仍在 `/` 展示空状态（NEmpty +「创建课表 / 导入课表」），不重定向到引导页；
2. **课表存在性校验**：进入 `/schedule/:id/settings` 或新增课程时，若 `:id` 对应的课表不存在，`scheduleStore` 给出错误提示并回退 `/`；
3. **未保存变更提示**（推荐实现，非 MVP 必需）：编辑课程/设置页存在未保存变更时，离开前使用 NDialog 提示确认。

## 7. 状态传递

- 路由参数只用于定位（`:id`），业务数据一律从 Pinia Store 读取；
- `CourseEditorView` 通过 `route.params.id` 判断新增（无 id）还是编辑（有 id），其余由 `courseStore` / `scheduleStore` 提供；
- 切课表通过 `scheduleStore.switchSchedule()` 更新 `activeScheduleId`，主课表与设置页自动跟随，无需刷新路由。

## 8. 路由与数据加载约定

```text
进入页面
  → Store 校验/初始化
  → Repository 读取
  → 页面展示
```

- 主课表：进入 `/` 时 `scheduleStore.loadSchedules()` + `courseStore` 一次性加载；之后切周只走 Engine，不重新查询；
- 设置页：进入 `/schedule/:id/settings` 时按 Tab 惰性加载，数据修改后保存按钮写入 Repository；
- 全局设置页：仅操作 `app_setting` 键值；
- 所有页面组件禁止直接 `db.select(...)`。
